Build the native Rust validator when exporting. The browser needs only static files and the shared WASM engine. No Python backend is used.

Supported imports and limits

Up to 16 populations, 100,000 total neurons, one million edges, 200 million neuron-ticks, 40,000 steps and 60 simulated seconds per population and two million recorded state values. Up to 64 probes and 32 trace variables per population. Four million recorded spikes per run.

Supports compatible AtlasIR exports with inline or procedural connectivity, delays, multiple clocks and portable functions. Native-only functions, external CSR files and custom EventMonitor recordings are not supported here. Record spikes with SpikeMonitor and states with StateMonitor.

Model and plan hashes are verified on Run. The exported model is executed as-is: no automatic resizing, parameter edits or WebGPU conversion. A .browser.json model bundle is required; arbitrary .wasm binaries have no compatible model interface.

Resource limits bound inputs and recordings, not total browser memory or runtime. Dense connectivity and complex equations can still be expensive. Stop terminates the Worker.
