Supported syntax and scope

1–4 dimensionless states, including v. Use dvariable/dt = expression : 1. Add (unless refractory) to freeze a state. Use ms or second for time units. t and dt are in seconds. Input drive comes from the slider, with seeded heterogeneity.

Arithmetic: + − * / **; powers 0–8; exp(), exprel(); comparisons and and/or/not. Up to 24 numeric parameters. Resets: =, +=, -=. Explicit Euler updates all derivatives from the old state. Thresholds are tested every step outside the refractory period.

This editor supports independent cells. Python, imports, functions, random calls inside equations, synapses and arbitrary units are not supported. WebGPU uses f32 and can differ from WASM/f64. Syntax and units are validated on Run.
